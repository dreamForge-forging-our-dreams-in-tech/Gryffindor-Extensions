# Opcode naming and block texts

## Use simple, recognizable and speakable names

When picking the name for your opcode you got to keep a few things in mind:

1. When picking the name of your opcode make sure that it can be pronounced as a whole sentence totgehter with your class name.

For example, you have a class name called "pickfiles" then a logical opcode name would be "select_file" which reads as "filepicker.select_file;" its read as a single sentence that you immediatly understand.

## Scratch requirements

When naming the opcode and adding text to blocks make sure that the name matches the text used in the opcode. for example you have a opcode named "pick_files" then that must also be used in the blocks text to ensure recognizability accross platforms
