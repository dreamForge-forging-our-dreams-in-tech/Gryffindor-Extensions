# ASD (Add source Directly) blocks

# IMPORTANT
This extension  can execute harmfull code, if you do not have to run this unsandboxed then DO NOT run it unsandboxed!
Only run it unsandboxed if you know what you are doing and absolutely need to use it!

## REPORTER
The REPORTER block of the ASD block family evaluates the given piece of code and rturns the result.

## COMMAND
The COMMAND block of the ASD block family evaluates the given piece of code without returning a result.
